```text
qcoach/
├── index.html                    # QCoach v3.0 live PWA (221 songs, Real-Time Chord Listening, YouTube Sync, Offline Mode)

│   ├── manifest.json             # Registry of modular JSON Song Packs

```

## Zero-Cost Hosting Setup
- **GitHub Pages (Live Immediately):** Push `index.html` + `packs/` to `Tortoi-ship-it/qcoach` (branch `main`).
- **Cloudflare Pages (Recommended for Public Scale):** Connect GitHub repo `Tortoi-ship-it/qcoach` in Cloudflare Pages -> Build command: *(leave empty)* -> Output directory: `/` -> Free global CDN with unlimited bandwidth.
- **Adding Thousands of Songs:** Drop new verified `.json` packs generated by the Python WhisperX pipeline into `packs/` (or import directly via **Settings -> Library -> Import JSON**).
